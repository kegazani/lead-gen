- [ ] 4.8 Реализовать дедупликацию переходов по одному письму (верификация: N переходов дают одно уведомление и N уточняющих записей)

- [ ] 4.10 Зафиксировать поведение для писем без отслеживаемых ссылок (верификация: письмо без ссылок остаётся в состоянии `unknown`, ложный сигнал не формируется)

## Why

Единая навигация админских консолей односторонняя. Канонический список разделов
(`components.ConsoleSections`) содержит только операторские разделы («Заявки»,
«Исполнение», «Лиды», «Отчёты», «Рассылки»), а платформенная консоль
(`platform-governance`) держит собственный список («Тенант», «Пользователи»,
«Регистрации», «Интеграции», «Аудит», «Топология», «Операции»). Поэтому
платформенная консоль (`/admin/...`) показывает обе группы, а операторские
консоли (`/intake`, `/lead-console`, `/reporting`, `/mailing`) — только
операторские: при клике по разделу сайдбар сужается.

Кроме того, платформенные разделы, требующие активного тенанта («Пользователи»,
«Интеграции», «Аудит», «Топология», «Операции»), берут тенант только из
`?tenant_id`. Ссылки навигации из раздела «Регистрации» (он платформенный, без
тенанта) тенант не несут, поэтому переход даёт «Не задан тенант» (400). Другие
консоли уже умеют читать выбранный оператором тенант из cookie `active_tenant`
(`consolescope`); платформенная — нет.

## What Changes

- **Единая двусторонняя навигация.** Канонический список разделов
  (`components.ConsoleSections`) дополняется платформенными разделами; они
  принадлежат сервис-ключу `ConsoleServicePlatform` (`platform-governance`) с
  путями: Тенант `/console/tenant`, Пользователи `/console/users`, Регистрации
  `/console/registrations`, Интеграции `/console/integrations`, Аудит
  `/console/audit`, Топология `/platform/topology`, Операции
  `/platform/operations`. Все консоли — четыре операторские (`/intake`,
  `/lead-console`, `/reporting`, `/mailing`) и платформенная (`/admin`) — строят
  сайдбар из одного списка, поэтому меню не сужается при переходах, а
  платформенные разделы видны и на операторских консолях.
- **Платформенный базовый адрес.** Базовый адрес платформенной консоли `/admin`
  (`-console-platform-base` / `CONSOLE_PLATFORM_BASE_PATH`) добавляется в
  `components.ConsoleBases` и пробрасывается во все пять сервисов как внешний
  префикс (`externalConsolePrefixes`): ссылки на платформенные разделы не
  переписываются чужой мидлварью.
- **Активность по ключу и по пути.** Общий слой отмечает активный раздел и по
  ключу раздела (операторские консоли передают ключ), и по префиксу адреса
  (платформенная консоль передаёт путь). Платформенная консоль отказывается от
  собственного списка пунктов и строится через общий слой без дублей.
- **Подписи из каталога.** Подписи платформенных разделов выносятся в общий
  каталог сообщений (`frontend/components/messages.go`, ключи `msgSection*`),
  откуда их берут навигация и шаблоны.
- **Тенант из cookie консоли.** Разделы определяют активный тенант как
  `tenant_id` из запроса/формы, затем — выбранный оператором тенант из cookie
  `active_tenant`, и переносят его в ссылки навигации.
- **Раздел без тенанта ведёт к выбору.** Экран, которому нужен активный тенант,
  при его отсутствии перенаправляет платформенного оператора на выбор тенанта
  (`/console/tenant`), а не отвечает «тенант не задан».

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `console-appearance`: канонический список разделов общей навигации дополняется
  платформенными разделами и показывается на всех консолях; изменяются прежние
  требования состава («Состав общей навигации операторской консоли», «Единый
  каркас навигации операторской консоли») — навигация теперь двусторонняя;
  активность определяется по ключу и по пути; платформенный базовый адрес
  пробрасывается во все сервисы.
- `client-portal` (административная часть): разделы, требующие тенанта,
  используют выбранный оператором тенант из cookie, а при его отсутствии ведут к
  выбору тенанта.

## Impact

- **Затрагиваемые bounded contexts:** `platform-governance` (HTTP-адаптер консоли,
  конфигурация сервиса), конфигурация точки входа `backend/cmd/lead-gen`. Общий
  слой `frontend/components` переиспользуется всеми консолями.
- **Код:** `frontend/components/{console.go,messages.go}`,
  `backend/cmd/lead-gen/{main.go,runners.go}`,
  `backend/contexts/platform-governance/internal/adapters/http/handlers_console.go`.
- **Доменная модель:** не меняется.

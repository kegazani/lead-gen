## ADDED Requirements

### Requirement: Решение читается только по запрошенной версии черновика

Владелец очереди утверждения (`outreach-orchestration`) SHALL возвращать решение
оператора по черновику только для **точной запрошенной версии** черновика. Решение
SHALL выдаваться лишь тогда, когда запрошенная версия совпадает с текущей версией
черновика и по этой версии принято решение. Если запрошенная версия не совпадает с
текущей (черновик доработан либо версия неизвестна), владелец SHALL NOT выдавать
решение иной версии как ответ на запрос: изменённый черновик требует нового
решения. Исходы чтения SHALL быть различимы и SHALL NOT смешиваться: несовпадение
версии или отсутствие решения — «решение не найдено»; отсутствие решения по текущей
версии черновика в ожидании — «решение ещё не принято»; отклонение — «отклонено»;
недоступность источника — честная недоступность, а не «решение не принято». Ни один
исход SHALL NOT маскироваться под положительное решение.

#### Scenario: Решение выдаётся по точной версии

- **WHEN** запрошена версия, совпадающая с текущей версией черновика, и по этой версии принято положительное решение
- **THEN** возвращается утверждённое действие, версия которого равна запрошенной

#### Scenario: Устаревшая версия после доработки не выдаётся

- **WHEN** черновик доработан (текущая версия выше запрошенной), в том числе когда по текущей версии уже принято решение
- **THEN** решение по запрошенной версии не выдаётся и действие не возвращается — исход «решение не найдено»

#### Scenario: Неизвестная версия не выдаётся

- **WHEN** запрошена версия, которой нет у черновика
- **THEN** решение не выдаётся — исход «решение не найдено»

#### Scenario: Решение по текущей версии ещё не принято

- **WHEN** запрошена текущая версия черновика, решение по ней отсутствует, черновик ожидает утверждения
- **THEN** возвращается исход «решение ещё не принято», а действие не возвращается

#### Scenario: Отклонение не выдаётся за утверждение

- **WHEN** по запрошенной версии (совпадающей с текущей) принято отрицательное решение
- **THEN** возвращается исход «отклонено», а действие не возвращается

#### Scenario: Отсутствие черновика или решения

- **WHEN** черновик по ссылке не найден либо действующего решения по запрошенной версии нет
- **THEN** возвращается исход «решение не найдено»

#### Scenario: Недоступность источника честна

- **WHEN** источник решения недоступен
- **THEN** возвращается честная недоступность, а не «решение не принято» и не положительное решение

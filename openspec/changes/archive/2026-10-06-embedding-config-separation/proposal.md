## Why

Живой прогон (клиент → заявка → админ → одобрение, 2026-10-04) показал: одобрение
заявки падает с **503**, workflow не стартует. Причина — системная связка
**чат и эмбеддинги в одном наборе `LLM_*`**:

- `vectorRecallPort` (`backend/cmd/lead-gen/runners.go`) собирает векторный порт
  по условию `supportGreenDSN != "" && LLM_API_KEY != ""` и передаёт в эмбеддер
  **те же** `LLM_BASE_URL`/`LLM_MODEL`, что и чат;
- при `LLM_BASE_URL=https://api.deepseek.com` и `LLM_MODEL=flash` вызов
  `POST /v1/embeddings` даёт `404` (у DeepSeek нет эмбеддингов);
- эмбеддинг оффера — шаг одобрения заявки (`semantic-lead-search`), поэтому
  одобрение отдаёт `эмбеддинг: векторное хранилище недоступно … 404`, а approve
  возвращает 503.

Итог: **нельзя использовать чат-провайдера без эмбеддингов** (DeepSeek) — цикл
блокируется на шаге одобрения. Это конфигурационный дефект, а не заглушка: чат
работает, а порт эмбеддингов требуется на пути одобрения и не может быть собран.

## What Changes

- Отделить конфигурацию эмбеддингов от чат-LLM: новые параметры
  `-embedding-base-url` / `-embedding-model` / `-embedding-key`
  (ENV `EMBEDDING_BASE_URL` / `EMBEDDING_MODEL` / `EMBEDDING_KEY`).
- `vectorRecallPort` собирается по **ключу эмбеддингов** (`EMBEDDING_KEY`), а не по
  `LLM_API_KEY`. Нет ключа эмбеддингов — векторный recall честно недоступен
  (семантика выключена), а одобрение заявки и остальной цикл работают.
- Чат (письма, планирование, диалог) продолжает использовать `LLM_*` без изменений.
- `.env.example`/`compose.yaml` описывают новый необязательный блок `EMBEDDING_*`.

- **Не входит:** смена провайдеров, изменение контракта `vector`/каталога, новые
  capability. `skip_specs` — изменение конфигурации/проводки без дельты требований.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Изменение — конфигурация и проводка `cmd`; поведение продуктовых требований
`vector-recall`/`semantic-lead-search` не меняется (при заданном ключе эмбеддингов
поведение прежнее; без ключа — честная недоступность, как и раньше при пустом LLM-ключе).

## Impact

**Код:** `backend/cmd/lead-gen` (флаги/ENV, `vectorRecallPort`), `compose.yaml`,
`.env.example`. Доменная модель, каталог, контракты, схема данных не меняются.

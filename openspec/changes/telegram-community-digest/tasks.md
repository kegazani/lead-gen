## 2. Подключение и хранение сессий

- [ ] 2.1 Реализовать подключение MTProto-клиента под пользовательским аккаунтом и подтверждение готовности к чтению (верификация: подключение с корректными данными завершается успешно, статус готовности доступен оператору)
- [ ] 2.2 Реализовать отклонение чтения при отсутствующей или недействительной сессии (верификация: запрос чтения без сессии не выполняет обращений к Telegram и возвращает требование авторизации)
- [ ] 2.3 Реализовать шифрованное хранилище сессий с доступом только для компонента чтения (верификация: данные авторизации недоступны другим компонентам; попытка чтения сессии из зелёной зоны завершается ошибкой)
- [ ] 2.4 Исключить вывод сохранённых учётных данных в интерфейс и журналы (верификация: аудит журналов и ответов интерфейса не находит данных авторизации)
- [ ] 2.5 Реализовать обнаружение недействительности сессии и уведомление оператора (верификация: при отзыве сессии система фиксирует событие и уведомляет оператора)

## 3. Пул аккаунтов и устойчивость к ограничениям

- [ ] 3.1 Реализовать поддержку нескольких аккаунтов чтения (верификация: система принимает и хранит более одной сессии, каждая изолирована)
- [ ] 3.2 Реализовать распределение нагрузки между аккаунтами с учётом лимитов каждого (верификация: при заданных пределах чтение не превышает предел ни по одному аккаунту)
- [ ] 3.3 Реализовать перевод чтения на резервный аккаунт при потере доступа и уведомление оператора (верификация: при имитации ограничения аккаунта чтение продолжается через резервный, оператор уведомлён)
- [ ] 3.4 Реализовать поведение при отсутствии резервных аккаунтов: остановка чтения, сохранение прочитанного, доступность ранее построенных выжимок (верификация: при потере единственного аккаунта чтение останавливается, ранее построенные выжимки доступны)
- [ ] 3.5 Реализовать обработку требования платформы приостановить обращения: пауза на указанный срок, возобновление после истечения, отсутствие потери данных (верификация: тест с имитацией требования приостановки не теряет прочитанное и возобновляет чтение)
- [ ] 3.6 Реализовать ограничение частоты обращений с постановкой избыточных в очередь (верификация: при достижении предела обращения ставятся в очередь, а не отбрасываются)

## 4. Чтение сообществ

- [ ] 4.1 Реализовать добавление сообщества в отслеживание и снятие с отслеживания (верификация: снятое с отслеживания сообщество не читается, ранее построенная выжимка сохраняется)
- [ ] 4.2 Реализовать чтение истории сообщества за заданный период или до заданного числа сообщений (верификация: чтение не выходит за заданные границы; границы фиксируются в результате)
- [ ] 4.3 Реализовать чтение как публичных, так и приватных сообществ, доступных аккаунту (верификация: чтение приватного сообщества выполняется без дополнительной настройки)
- [ ] 4.4 Реализовать непрерывное чтение по расписанию с фиксацией времени последнего успешного чтения (верификация: новое сообщение попадает в очередное обновление без отдельного запроса оператора)
- [ ] 4.5 Реализовать настройку частоты обновления по сообществу (верификация: чтение выполняется с заданной частотой; значение частоты сохраняется и применяется после перезапуска)
- [ ] 4.6 Реализовать фиксацию недоступности сообщества без остановки чтения остальных (верификация: при недоступности одного сообщества чтение остальных продолжается, недоступность зафиксирована)

## 5. Разделение данных по зонам

- [ ] 5.1 Реализовать разделение содержания и авторства при обработке: авторство отделяется на входе и направляется в красную зону (верификация: в зелёной зоне отсутствуют записи, связывающие содержание с автором)
- [ ] 5.2 Реализовать получение состава участников с помещением в красную зону (верификация: состав участников сохранён в красной зоне и недоступен для выгрузки)
- [ ] 5.3 Реализовать частичный результат при недоступности состава без подмены оценкой (верификация: при недоступности состава система сообщает о частичном результате; отсутствующие данные не заполняются расчётными)
- [ ] 5.4 Реализовать отклонение выгрузки данных красной зоны за пределы контура (верификация: запрос выгрузки авторов или состава отклоняется с указанием причины)
- [ ] 5.5 Реализовать выгрузку выжимки без идентифицирующих данных авторов (верификация: выгрузка не содержит имён, аккаунтов и идентификаторов авторов)
- [ ] 5.6 Реализовать окно обработки: хранение прочитанных сообщений ограничено, по истечении сохраняются только выжимка, обезличенные цитаты и ссылки на источник (верификация: по истечении окна полные тексты сообщений отсутствуют в хранилище)

## 6. Формирование выжимки содержания

- [ ] 6.1 Реализовать построение выжимки по сообществу за период: перечень тем с частотой упоминаний и примерами формулировок (верификация: выжимка содержит темы и частоты; примеры не содержат имён и аккаунтов)
- [ ] 6.2 Реализовать выделение повторяющихся запросов и возражений отдельным пунктом с числом повторений (верификация: однотипные формулировки объединяются, число повторений соответствует исходным сообщениям)
- [ ] 6.3 Реализовать расчёт динамики темы между периодами (верификация: при данных более чем за один период система показывает изменение частоты)
- [ ] 6.4 Реализовать обработку случая «сообщений за период нет» без формирования пустой выжимки с нулями (верификация: при отсутствии сообщений система сообщает об отсутствии данных, нулевые значения не подставляются)
- [ ] 6.5 Реализовать изоляцию выжимок по сообществам без неявной агрегации между ними (верификация: пункт выжимки ссылается на одно сообщество; сводка по нескольким сообществам формируется только по явному запросу)
- [ ] 6.6 Реализовать порог по размеру сообщества для включения цитат (верификация: цитаты из сообществ ниже порога в выжимку не попадают)

## 7. Прослеживаемость

- [ ] 7.1 Реализовать связь каждого пункта выжимки с сообществом, периодом и сообщениями-источниками (верификация: запрос источника по пункту возвращает сообщество, период и сообщения без данных авторов)
- [ ] 7.2 Реализовать пометку источника как удалённого без пересчёта прошлой выжимки (верификация: после удаления сообщения в Telegram связь сохраняется, пометка выставлена, прошлая выжимка не изменена)
- [ ] 7.3 Реализовать хранение выжимок с указанием периода построения (верификация: для сообщества доступны выжимки за разные периоды с указанием границ)

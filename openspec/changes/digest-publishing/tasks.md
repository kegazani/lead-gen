- [ ] 1.2 Уточнить в `openspec/changes/full-enterprise-core-scope/design.md` таблицу Решения 9: строка `3.13 LinkedIn` получает пометку о публикации через официальный API (верификация: таблица не противоречит `design.md` изменения `digest-publishing`)

- [ ] 1.4 Закрепить в документах запрет на автоматизацию сессии и браузера для публикации (верификация: запрет присутствует в BRD §7 и в спеке; `openspec validate digest-publishing --strict` проходит)

## 2. Выжимка как источник

- [ ] 2.1 Реализовать выбор выжимки как источника публикации с указанием сообщества и периода (верификация: состав выжимки отображается, сообщество и период зафиксированы)
- [ ] 2.2 Реализовать отказ при отсутствии выжимки по выбранному сообществу (верификация: публикация не формируется, оператор уведомлён)
- [ ] 2.3 Реализовать запрет формирования публикации из непереработанных сообщений: доступ к сырым сообщениям из модуля публикации отсутствует (верификация: проверка зависимостей не находит обращений к хранилищу сообщений и к данным авторов)
- [ ] 2.4 Реализовать предупреждение об устаревшей выжимке с требованием подтверждения (верификация: при возрасте источника выше предела система требует подтверждения перед переработкой)

## 3. Переработка под площадки

- [ ] 3.1 Реализовать формирование отдельного материала под каждую выбранную площадку (верификация: для Дзена, LinkedIn и Telegram формируются разные материалы, а не один)
- [ ] 3.2 Реализовать учёт формата и ограничения длины каждой площадки (верификация: материал соответствует формату площадки; при превышении объёма текст сокращается с сообщением о сокращении)
- [ ] 3.3 Реализовать переработку текста через capability `linguistics` с передачей тональности и языка (верификация: собственный механизм генерации текста в модуле отсутствует; тональность и язык применяются)
- [ ] 3.4 Реализовать формирование материала только под выбранные площадки (верификация: при выборе одной площадки материалы для остальных не создаются)

## 4. Запреты в материале

- [ ] 4.1 Реализовать переформулирование дословных цитат участников в обобщения (верификация: цитата из выжимки не попадает в публикацию дословно)
- [ ] 4.2 Реализовать удаление признаков автора высказывания: имён, аккаунтов, ссылок на профили (верификация: тестовый материал с признаком автора очищается, факт удаления зафиксирован)
- [ ] 4.3 Реализовать проверку материала на персональные данные с запретом публикации при обнаружении (верификация: при обнаружении сведений о физлице публикация не выполняется, оператор уведомлён)
- [ ] 4.4 Реализовать запрет на сведения, отсутствующие в выжимке: числовые показатели, сроки, гарантии, результаты (верификация: при отсутствии сведений в источнике они не появляются в материале)
- [ ] 4.5 Реализовать порог по размеру сообщества для публикаций, строже порога для внутренних выжимок (верификация: сообщество ниже порога не даёт публикацию, причина сообщается)

## 5. Утверждение

- [ ] 5.1 Реализовать представление материала оператору до публикации (верификация: публикация недоступна, пока материал не показан)
- [ ] 5.2 Реализовать утверждение материала как отдельное действие с фиксацией автора и времени (верификация: запись об утверждении сохранена; публикация без утверждения не выполняется)
- [ ] 5.3 Реализовать отклонение материала без публикации (верификация: отклонённый материал остаётся неисполненным и не публикуется)
- [ ] 5.4 Реализовать расписание, формирующее материал к сроку без права публикации (верификация: по расписанию материал подготовлен и ожидает утверждения; автоматической публикации не происходит)

## 6. Канал Дзен

- [ ] 6.1 Реализовать публикацию в Дзен через официальный API с авторизацией по OAuth (верификация: материал публикуется через официальный интерфейс; иные способы в конфигурации отклоняются)
- [ ] 6.2 Реализовать проверку наличия доступа к API Дзена до формирования материала (верификация: при отсутствии доступа канал помечен неготовым, материал для него не формируется)

## 7. Канал LinkedIn

- [ ] 7.1 Реализовать публикацию в LinkedIn через официальный API публикаций с авторизацией по OAuth (верификация: материал публикуется через официальный интерфейс)
- [ ] 7.2 Реализовать проверку действительности авторизации LinkedIn (верификация: при отсутствующей или истёкшей авторизации система сообщает о необходимости авторизации и не публикует)
- [ ] 7.3 Реализовать отклонение конфигураций с автоматизацией браузера, сессией пользователя или сторонней библиотекой (верификация: конфигурация с запрещённым способом отклоняется, публикация не выполняется)

## 8. Канал Telegram

- [ ] 8.1 Реализовать публикацию в сообщество Telegram через Bot API (верификация: материал публикуется в сообщество, бот является администратором)
- [ ] 8.2 Реализовать проверку прав бота в сообществе (верификация: при отсутствии прав администратора система сообщает о невозможности публикации и не пытается обойти ограничение)

## 8а. Канал Instagram

- [ ] 8а.1 Реализовать публикацию через официальный интерфейс публикации контента (верификация: материал публикуется через официальный интерфейс; иные способы в конфигурации отклоняются)
- [ ] 8а.2 Реализовать проверку типа аккаунта: публикация только с профессионального аккаунта (верификация: при личном аккаунте публикация не выполняется, система сообщает о необходимости перевести аккаунт)
- [ ] 8а.3 Реализовать отклонение конфигураций с извлечением содержимого со страниц Instagram, автоматизацией браузера или сессии и сторонними библиотеками (верификация: каждая такая конфигурация отклоняется, публикация не выполняется)
- [ ] 8а.4 Реализовать проверку готовности канала до формирования материала: одобрение приложения и действительность авторизации (верификация: при неготовности канала материал не формируется, причина сообщается)
- [ ] 8а.5 Реализовать построение визуального материала как обязательной части публикации (верификация: при отсутствии визуальной части публикация не выполняется)
- [ ] 8а.6 Реализовать размещение визуального материала по адресу, доступному площадке (верификация: площадка получает материал по адресу; при недоступности адреса публикация не выполняется и обход не предпринимается)
- [ ] 8а.7 Реализовать формирование подписи без опоры на ссылку как призыв к действию (верификация: подпись содержит призыв, не сводящийся к ссылке)
- [ ] 8а.8 Реализовать двухшаговую публикацию: создание контейнера, ожидание подтверждения готовности, публикация (верификация: публикация контейнера без подтверждённой готовности не выполняется)
- [ ] 8а.9 Реализовать обработку случая, когда готовность не подтверждена в срок (верификация: публикация не выполняется, оператору сообщается причина)
- [ ] 8а.10 Реализовать соблюдение суточного предела площадки как потолка с уведомлением о приближении (верификация: при приближении к пределу публикации приостанавливаются; достижение предела не используется как целевой режим)

## 9. Ограничения площадок

- [ ] 9.1 Реализовать ограничение частоты публикаций по площадке с постановкой в очередь (верификация: при достижении заданной частоты публикация ставится в очередь, предел не превышается)
- [ ] 9.2 Реализовать запрет повторной публикации уже опубликованного материала (верификация: повторный выбор опубликованного материала отклоняется со ссылкой на предыдущую публикацию)
- [ ] 9.3 Реализовать запрет публикации дословно совпадающих материалов на разных площадках (верификация: при совпадении система требует переработки под формат площадки)

## 10. Фиксация результата

- [ ] 10.1 Реализовать запись по каждой публикации: площадка, время, утвердивший оператор, результат, адрес материала (верификация: запись содержит все перечисленные поля)
- [ ] 10.2 Реализовать фиксацию причины отказа площадки без автоматического повтора и с уведомлением оператора (верификация: при отказе причина сохранена, повторной публикации не происходит, оператор уведомлён)

## 11. Интеграционная проверка

- [ ] 11.1 Провести сквозной сценарий: выбор выжимки, формирование материалов под три площадки, утверждение, публикация (верификация: материалы различаются по площадкам; публикация выполнена только после утверждения)
- [ ] 11.2 Провести проверку границы: аудит зависимостей и хранилищ после полного цикла (верификация: модуль не обращается к сырым сообщениям и данным авторов; персональные данные в публикациях отсутствуют)
- [ ] 11.3 Провести проверку запретов: попытки публикации без утверждения, повторной публикации и публикации с персональными данными (верификация: каждая попытка отклоняется с сообщением причины)
- [ ] 11.4 Проверить выполнение требований спеки по capability `digest-publishing` (верификация: `openspec validate digest-publishing --strict` проходит без ошибок)

## 4. Очередь утверждений

- [ ] 4.1 Реализовать список очереди с фильтрами и колонкой результата автоматических проверок (согласие, стоп-лист, лимиты, готовность домена, верификация адреса) (верификация: тест показывает результат проверок по каждому черновику)
- [ ] 4.2 Реализовать экран индивидуального решения: данные лида, контент, вложение, история касаний, результат проверок (верификация: тест предъявляет все пять составляющих до принятия решения)
- [ ] 4.3 Реализовать решения: подтвердить, отредактировать и подтвердить, отклонить с причиной, отложить; правки хранятся отдельно от сгенерированного (верификация: тест фиксирует отдельную запись правок и автора)
- [ ] 4.4 Реализовать пакетное решение с обязательным предъявлением состава: число черновиков, основание однородности, образец, отличия, число исключённых с причинами (верификация: тест запрещает решение без предъявления состава)
- [ ] 4.5 Реализовать визуальное отделение рисковых черновиков и их исключение из пакета (верификация: рисковый черновик не входит в пакет и требует индивидуального решения)
- [ ] 4.6 Реализовать срез зависших черновиков без автоутверждения (верификация: по истёкшему сроку действие остаётся неисполненным и оператор получает уведомление)
- [ ] 4.7 Реализовать пагинацию и масштаб очереди: пакет не менее 50 черновиков, кампания на 50 000, счётчики до и после фильтра (верификация: тест показывает пакет из 50 черновиков и навигацию по очереди кампании 50 000 без открытия всех страниц)
- [ ] 4.8 Реализовать уведомление ответственного о появлении новых черновиков и о зависших дольше срока (верификация: тест показывает счётчик/уведомление о новых черновиках; уведомление не исполняет действие и не заменяет решение)

- [ ] 5.3 Реализовать раздел кампаний: список, карточка, ссылка на снимок аудитории (верификация: тест показывает, что кампания ссылается на снимок, а не на живой сегмент)
- [ ] 5.4 Реализовать раздел цепочек: сценарии, выполнения, шаги, звонки, form-задания (верификация: тест показывает состояние выполнения и причину паузы; форма-действие исполняет человек, а не платформа)

- [ ] 7.5 Реализовать просмотр и экспорт журнала аудита без возможности правки записей (верификация: тест подтверждает неизменяемость и наличие субъекта, действия, объекта, времени и результата)

- [ ] 7.7 Реализовать выход и истечение сессии: завершение серверной сессии, истечение по неактивности, возврат к странице входа (верификация: по истечении сессии пользователь перенаправляется на вход, данные экрана не отдаются)

- [ ] 6.1 На изолированном свежем harness пройти через UI регистрацию → административное одобрение профиля → login → request с отдельными offer/desired leads → admin approve/start → реальный provider crawl; затем открыть существующую вкладку «Операции» и подтвердить для этого request реальные связанные execution data и status, совпадающие с источником исполнения. Зафиксировать request ID, найденный lead и наблюдаемые данные в UI без секретов и персональных данных. «Данные процесса недоступны», отсутствие данных или подмена httptest doubles не являются успешным evidence.

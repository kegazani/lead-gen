## 1. Документы (предусловие)

- [ ] 1.1 Закрыть вопрос 21 BRD §8: capability под движки 3.10 и 3.15 созданы (верификация: вопрос помечен закрытым со ссылкой на изменение `sequences-and-reporting`)
- [ ] 1.2 Убрать движки 3.10 и 3.15 из перечня «Движки без capability» в BRD §7 (верификация: перечень содержит один движок — 3.17; `openspec validate sequences-and-reporting --strict` проходит)

## 2. Конструктор сценариев

- [ ] 2.1 Реализовать конструктор сценария: шаг, тип действия, задержка, условие перехода (верификация: сценарий сохраняется и запускается)
- [ ] 2.2 Реализовать задержку шага (верификация: черновик формируется не ранее указанного срока после предыдущего шага)
- [ ] 2.3 Реализовать переход по умолчанию при отсутствии условия (верификация: сценарий без условия перехода исполняется последовательно)

## 3. Черновики и утверждение

- [ ] 3.1 Реализовать порождение черновика шага и помещение его в очередь утверждений (верификация: черновик появляется в очереди, отправка не выполняется)
- [ ] 3.2 Убедиться в отсутствии доступа к отправке из модуля цепочек (верификация: проверка зависимостей не находит обращений к компоненту отправки)
- [ ] 3.3 Реализовать отдельное утверждение каждого шага (верификация: утверждение шага не утверждает последующие; черновики остальных шагов остаются неутверждёнными)

## 4. Запрет автоутверждения

- [ ] 4.1 Реализовать бессрочное ожидание утверждения без автоутверждения по сроку (верификация: по истечении срока шаг остаётся неисполненным, автоутверждения не происходит)
- [ ] 4.2 Реализовать уведомление о простое цепочки (верификация: при наличии неутверждённых шагов система уведомляет и не предпринимает действий по их исполнению)
- [ ] 4.3 Убедиться в отсутствии пропуска неутверждённого шага (верификация: цепочка не переходит к следующему шагу и не исключает неутверждённый)
- [ ] 4.4 Реализовать вывод объёма неутверждённых шагов как отдельного показателя (верификация: показатель отображается в отчётности)

## 5. Ветвление

- [ ] 5.1 Реализовать ветвление по условиям «перешёл», «не перешёл», «ответил», «не ответил» (верификация: цепочка переходит по соответствующей ветке)
- [ ] 5.2 Исключить признак открытия из перечня условий перехода (верификация: признака нет в перечне; попытка задать его отклоняется)
- [ ] 5.3 Реализовать классификацию входящего ответа через `linguistics` для выбора ветки (верификация: ответ классифицируется; при неуверенной классификации ветка не выбирается автоматически)

## 6. Приостановка и остановка

- [ ] 6.1 Реализовать приостановку цепочки при получении ответа (верификация: последующие шаги не формируются)
- [ ] 6.2 Реализовать остановку при отписке, жёстком отказе и попадании в стоп-лист (верификация: цепочка остановлена и не подлежит возобновлению)
- [ ] 6.3 Реализовать возобновление после приостановки только решением оператора (верификация: автоматического возобновления не происходит; после решения оператора цепочка продолжается)

## 7. Ограничения участия

- [ ] 7.1 Реализовать предел числа касаний по одному лиду за период (верификация: при достижении предела новые черновики не формируются)
- [ ] 7.2 Реализовать суммирование касаний по всем цепочкам одного лида (верификация: участие в нескольких цепочках не превышает общий предел)
- [ ] 7.3 Реализовать ручное добавление и удаление лида из цепочки (верификация: добавление формирует первый шаг; удаление прекращает последующие и фиксируется в журнале)
- [ ] 7.4 Реализовать предел общего объёма черновиков со приостановкой формирования (верификация: при достижении предела формирование останавливается, оператор уведомлён)

## 8. Журнал выполнения

- [ ] 8.1 Реализовать журнал: шаг, время, результат, утвердивший оператор (верификация: запись присутствует по каждому исполненному и отклонённому шагу)
- [ ] 8.2 Реализовать отображение истории шагов по лиду (верификация: отображаются все шаги всех цепочек с результатами)

## 9. Отчётность по кампаниям и лидам

- [ ] 9.1 Реализовать дашборд кампании: отправлено, доставлено, переходы, ответы, отписки, отказы (верификация: метрики отображаются за период)
- [ ] 9.2 Исключить метрику открытий из дашборда и из выгрузок (верификация: метрики открытий нет ни в интерфейсе, ни в выгрузке)
- [ ] 9.3 Реализовать дашборд лидогенерации по источникам, отраслям и периодам (верификация: распределения соответствуют фильтрам)
- [ ] 9.4 Реализовать воронку «лид → коммуникация → ответ → сделка» с конверсией (верификация: этапы и конверсия отображаются; расчёт проверен на известных числах)
- [ ] 9.5 Реализовать отчёт по качеству базы: доля валидных, доля отказов, доля дублей (верификация: три доли отображаются и пересчитываются по фильтру кампании)

## 10. Управленческая отчётность

- [ ] 10.1 Реализовать отчёт по активности менеджеров: объём и конверсия (верификация: отчёт отображается отдельным разделом)
- [ ] 10.2 Убедиться в разделении управленческой отчётности и отчётности по лидам (верификация: сведения о сотрудниках не появляются в отчётах по лидам)

## 11. Агрегация и границы

- [ ] 11.1 Реализовать расчёт отчётов в контуре клиента с передачей только агрегатов (верификация: записи пула на платформу не передаются; аудит подтверждает)
- [ ] 11.2 Реализовать порог минимальной группы для отображения среза (верификация: срез ниже порога не отображается, причина сообщается)
- [ ] 11.3 Реализовать тот же порог для выгрузки (верификация: срезы ниже порога в выгрузку не попадают)
- [ ] 11.4 Реализовать честную деградацию при недоступности контура клиента (верификация: показываются последние метрики с явным временем; отсутствующие значения нулём не подменяются)

## 12. Фильтрация, выгрузка и актуальность

- [ ] 12.1 Реализовать фильтрацию по периоду, сегменту, источнику и кампании (верификация: комбинация фильтров даёт корректный срез)
- [ ] 12.2 Реализовать выгрузку в CSV и XLSX (верификация: оба формата содержат метрики за выбранный период)
- [ ] 12.3 Реализовать обновление метрик с указанием времени последнего обновления (верификация: время отображается; задержка соответствует заданному интервалу)

## 13. Интеграционная проверка

- [ ] 13.1 Провести сквозной сценарий: сценарий цепочки, черновики, утверждение, ветвление, остановка (верификация: сценарий проходит; ни один шаг не исполнен без утверждения)
- [ ] 13.2 Провести проверку запрета автоутверждения (верификация: имитация длительного отсутствия утверждений не приводит к исполнению шагов)
- [ ] 13.3 Провести проверку границы отчётности (верификация: аудит хранилищ платформы не находит записей пула; малые срезы не отображаются и не выгружаются)
- [ ] 13.4 Проверить выполнение требований спек по обеим capability (верификация: `openspec validate sequences-and-reporting --strict` проходит без ошибок)

## ADDED Requirements

### Requirement: Тематическое письмо использует доступные факты компании

При генерации письма система SHALL использовать актуальные факты компании-отправителя, если они доступны в существующем рабочем контуре, и описание желаемых лидов. Отдельный замороженный sender snapshot не обязателен. Генерация выполняется реальным настроенным LLM; тестовые двойники допустимы только в тестах.

#### Scenario: Генерация с доступными фактами компании
- **WHEN** найден лид и доступно описание offer/services компании
- **THEN** реальный LLM получает эти факты и тематическое описание запроса для генерации письма

#### Scenario: Факты компании недоступны
- **WHEN** текущие данные компании недоступны генератору
- **THEN** сценарий явно фиксирует этот блокер; не подменяет результат фиктивным письмом

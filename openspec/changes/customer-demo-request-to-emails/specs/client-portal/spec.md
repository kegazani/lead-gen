## ADDED Requirements

### Requirement: Подача клиентского запроса

Портал SHALL использовать существующие регистрацию и одобрение профиля. Одобренный клиент SHALL иметь возможность передать предложение своей компании отдельно от описания желаемых лидов в существующем request flow.

#### Scenario: Запрос одобренного клиента
- **WHEN** клиент с одобренным профилем отправляет offer и desired leads
- **THEN** оба значения передаются раздельно в существующий request flow для активного tenant

#### Scenario: Профиль не одобрен
- **WHEN** клиент без одобренного профиля отправляет запрос
- **THEN** действует существующее ограничение доступа и заявка не создаётся

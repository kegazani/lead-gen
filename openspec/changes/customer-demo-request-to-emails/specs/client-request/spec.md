## ADDED Requirements

### Requirement: Offer и desired leads разделены

Существующая заявка SHALL сохранять предложение компании (offer/services) отдельно от описания желаемых лидов. Одобрение выполняется существующим операторским процессом.

#### Scenario: Подача заявки
- **WHEN** авторизованный клиент с одобренным профилем подаёт offer и описание желаемых лидов
- **THEN** оба текста сохраняются в соответствующих отдельных полях request активного tenant

#### Scenario: Оператор одобряет заявку
- **WHEN** оператор одобряет созданную заявку существующим экраном
- **THEN** запускается текущий request execution путь

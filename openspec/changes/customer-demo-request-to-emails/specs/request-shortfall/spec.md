## ADDED Requirements

### Requirement: Генерация писем найденным лидам не зависит от shortfall

В демонстрационном request flow система SHALL запрашивать генерацию письма для найденных лидов независимо от достижения desired lead target. Это изменение не требует менять иные delivery сценарии вне указанного demo пути.

#### Scenario: Target достигнут
- **WHEN** crawl/search нашёл лидов и target уже достигнут
- **THEN** генерация писем для найденных лидов всё равно запрашивается

#### Scenario: Target не достигнут
- **WHEN** crawl/search нашёл лидов и остаётся shortfall
- **THEN** генерация писем для найденных лидов запрашивается

#### Scenario: Нет лидов
- **WHEN** поиск не нашёл лидов
- **THEN** система не выдумывает письма

# Технические границы исследовательского задания

Текущий путь `SearchBrief → planner → mission → research analysis` проверяет вход
до планирования, одобрения в исследовательской форме и вызовов Firecrawl.
Владелец опубликованной проверки — `researchplan.SearchBrief.Validate`; создание
через `NewBrief`, компиляция через `Planner.Plan` и валидация сохраняемого плана
используют эту проверку. Это технические границы текущей реализации change
`intelligent-lead-research`, а не ограничение полной программы поиска.

| Поле | Допустимый предел |
| --- | --- |
| Оффер | 8000 Unicode символов |
| ICP | 8000 Unicode символов и одновременно 16000 байт UTF-8 |
| Must + Should + Exclude | 38 критериев суммарно, до 32 в каждой группе |
| Unknown | До 32 дополнительных неизвестностей; не превращаются в обязательные условия |
| ID критерия | 128 байт UTF-8, уникальный во всём снимке; префикс `__human_` зарезервирован |
| Текст отдельного критерия | 1000 Unicode символов |
| tenant_id и purpose | 200 байт UTF-8 каждый, совместимо с областью памяти |

Строки должны содержать корректный UTF-8. Например, ICP из 8000 русских букв
занимает 16000 байт и допустим; идентификатор из 64 русских букв занимает 128 байт
и допустим. Более длинная строка отклоняется с объяснением, а не обрезается.

Extraction допускает 40 оцениваемых условий: до 38 введённых условий и два
служебных — полный человеческий ICP и выбранный рынок. Неизвестности остаются
в immutable brief и входят в контекст планирования; они не считаются доказанными
критериями при оценке компании. Все Must/Should/Exclude передаются без изменения
ID, текста и вида. Превышение предела требует изменения задания человеком или
будущего явно спроектированного разбиения оценки; молчаливое удаление условий
запрещено. Лимит output tokens модели этим изменением не повышается.

Проверки: `contracts/agent-orchestration/researchplan/plan_test.go`,
`backend/contexts/agent-orchestration/internal/app/researchplanner/planner_test.go`
и `backend/cmd/lead-gen/research_input_limits_test.go`. Последний проводит
максимальный русский ICP/ID и все четыре группы через настоящий root bridge и
Analyzer до тестовой модели, проверяя полный extraction request. Он не выдаётся
за платный эксперимент качества LLM.

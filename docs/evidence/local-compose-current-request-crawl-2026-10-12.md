## Что прошло и что нет

- В новом браузере через Playwright синтетическая регистрация `DemoCrawl20261012` принята. Это не прошедшая регистрацию/profile approval заявка и не тестовый crawl.
- Вход оператора из браузера не прошёл: staged password file содержит завершающий LF, который передаётся как часть секрета. Сам секрет не копировался и не выводился. Предлагаемое узкое исправление — убрать один завершающий LF при чтении; оно ожидает согласия пользователя и не должно обходить аутентификацию.
- Ни одобрение/вход зарегистрированного пользователя, ни создание/одобрение заявки, ни crawl, сохранение leads, отмена или проверка операций в браузере не подтверждены. Прежний HTTP-ответ об отсутствии operator auth относится к старому основному Compose и не характеризует этот контур.
- UI-исправления подписей статусов/истории и отмены с `WorkflowNotFound` имеют прошедшие целевые тесты. Источник операций добавлен и подключён в HTTP adapter. Более новые подписи уже есть в исходниках, но запущенный runtime не пересобирался под эту версию; не утверждать, что они отображаются в живом контуре.
- Семантический выбор остаётся открытым: вариант A — исполнение после draft, вариант B — после поиска. До согласия пользователя считать ни один выбранным.
- `make check` повторно запущен, итогового результата пока нет. Предыдущие успешные importlint/archlint результаты не являются результатами этого запуска; известная ранее проблема archlint — отсутствующая capability spec `content-production`. `go -C tools/archlint run .` и strict validation не объявляются пройденными в этой промежуточной записи. Чекбоксы задач не менялись.

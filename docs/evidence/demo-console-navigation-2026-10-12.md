# Проверка навигации локального демо

Изменение: `customer-demo-request-to-emails`, задача 11. Проверялся отдельный
`lead-gen-demo` с сохранёнными данными предыдущего реального Firecrawl/LLM прогона.
Доставка писем не запускалась.

## Наблюдаемые причины

- Lead API хранил операторские сессии в собственной lead DB, тогда как админка
  и заявки использовали support DB. Переход требовал повторного входа.
- Проверка доступа к списку компаний зависела от активного tenant. Устаревший
  адрес или cookie давали 404, не оставляя возможности сменить выбор.
- Очередь без выбранной компании выглядела пустой.
- В demo Compose отсутствовали analytics и маршрут `/reporting`.

## Результат проверки

- Проверены адресные тесты трёх затронутых контекстов, тесты сборки сервисов,
  `go vet` и сборка служебного бинарника. `openspec validate
  customer-demo-request-to-emails --strict` прошёл.
- Обновлённые app/demand и новый reports запущены со старыми demo volumes.
  Nginx перезапущен для перечитывания bind-mounted конфигурации.
- В Chromium выполнен один вход admin и переход по ссылкам меню: «Заявки» →
  «Исполнение» → «Лиды» → «Пользователи» → «Регистрации» → «Интеграции» →
  «Аудит» → «Топология» → «Операции» → «Отчёты» → «Заявки». Все страницы
  ответили 200, сохраняли компанию и не требовали нового входа.
- Адрес выбора с отсутствующим tenant ответил 200; после выбора существующей
  компании показаны её пользователь и сохранённая завершённая заявка.
- В карточках через вкладку «Не оценено» виден лид из реального crawl.
- HTML-выгрузка отчёта принята с CSRF общей сессии и открыла страницу прогресса.
  Ошибок JavaScript в этом браузерном сценарии нет.

## Границы результата

Отчётность отражает существующую аналитическую проекцию. В демо без доставки
показатели доставки могут быть пустыми. Топология без Prometheus продолжает
показывать неизвестные метрики. Полная продуктовая готовность не заявляется.

Общий `make check` остановился на прежних тестах владельца/прав secret files
в облачном окружении. Отдельные lint-проверки также нашли прежние проблемы:
`archlint` — отсутствие capability `content-production` в OpenSpec;
`importlint` — импорт outbox adapter из теста app в `message-delivery`.
Эти файлы не менялись. Задачи изменения не отмечены выполненными, поскольку
полный гейт AGENTS.md пока не зелёный.
